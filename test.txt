普通纪念币预约系统 - 手工联调步骤（先到先得、约满为止）

说明：提交预约那一刻即占用所选网点额度，并当场返回预约号（orderNo），
      用户此时就已知晓「约上了没有」，没有独立的抽签/分配环节。

步骤 1：实名预填（必须最先做）
curl -X POST http://localhost:8083/api/user/qualify \
  -H 'Content-Type: application/json' \
  -d '{"userId":1001,"idCard":"110101199001011234","name":"张三","phone":"13800000001"}'
→ 期望 code:0（同时写入 Redis qual:ok:1001，有效期 1 小时）

步骤 2：查看产品和网点额度（可选，验证数据）
curl http://localhost:8084/api/product/list
curl http://localhost:8084/api/product/1/branches

步骤 3：额度预热（必须做，否则网点额度在 Redis 里为 0，提交必返回 1001）
curl -X POST http://localhost:8084/api/product/1/init-stock
→ 把 PG 里网点额度拆成 10 个分片写入 Redis，并登记网点清单 resv:branches:1

步骤 4：查各网点剩余额度（前端据此展示余量、避开已约满网点）
curl http://localhost:8081/api/reservation/stock/1
→ 期望 code:0，data 为 [{branchId:1,remain:300},{...}]

步骤 5：提交预约（选网点 1）
curl -X POST http://localhost:8081/api/reservation/submit \
  -H 'Content-Type: application/json' \
  -d '{"productId":1,"branchId":1,"userId":1001,"idCard":"110101199001011234","token":"token-1001"}'
→ 期望 code:0，data.orderNo 为预约号（例如 1234567890123456789），
  data.sequenceNo 为预约顺序号（第 N 位约上的人），data.branchRemain 为扣减后该网点余量

步骤 6：重复提交（验证幂等）
同步骤 5 再发一次（token 不变）
→ 期望 code:1003（请勿重复提交）

步骤 7：换 token、同一身份证再约（验证「重复预约无效」）
curl -X POST http://localhost:8081/api/reservation/submit \
  -H 'Content-Type: application/json' \
  -d '{"productId":1,"branchId":1,"userId":1001,"idCard":"110101199001011234","token":"token-1001-b"}'
→ 期望 code:1002（超过限购数量，即该身份证已约过）

步骤 8：命中已约满网点（验证网点级失败原因，供前端引导换网点）
把某个网点约满后，再向该网点提交
→ 期望 code:1001（该网点已约满）；前端应提示用户改选其它网点

步骤 9：不在预约期内（验证活动时间窗）
把 t_product.submit_start 改到未来，再提交
→ 期望 code:1008（活动尚未开始）；submit_end 已过则返回 1009（活动已结束）

步骤 10：等 3~5 秒（Kafka 异步落库）

步骤 11：查询预约明细
curl "http://localhost:8082/api/order/list?idCard=110101199001011234"
→ 期望返回预约记录（含 orderNo、sequenceNo、branchId、status=1），
  记下 orderNo（下一步要用）

步骤 12：兑换登记（用上一步的 orderNo）
curl -X POST http://localhost:8085/api/exchange/register \
  -H 'Content-Type: application/json' \
  -d '{"orderNo":"把步骤11的orderNo粘这里","idCard":"110101199001011234","branchId":1,"operatorId":9001}'
→ 期望 code:0

步骤 13：重复兑换（验证状态机）
同步骤 12 再发一次 → 期望 code:1010（该预约已兑换）

四、现成脚本
scripts/e2e-test.sh 已把上述流程串好（走网关 8080），你在 IDEA 起好服务后可直接跑：
bash scripts/e2e-test.sh
